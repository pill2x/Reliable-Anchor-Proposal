Site Evaluation & Deductions

⚓

A corporate enterprise trusted to manage maritime freight, customs compliance, and supply chains requires a seamless digital presence. The current platform relies on basic, traditional, decoupled HTML documents. This presents massive operational limitations and navigation anomalies that quietly degrade user trust and interrupt the client acquisition funnel.

✓ Strengths

Current Structural Foundation

The current platform establishes a useful baseline layout: a multi-tiered dropdown service navigation, dedicated sector pages, a functional contact collection form, an "Importer's Guide" knowledge asset, and dynamic client recommendation blocks. However, these are managed entirely as hardcoded, decoupled assets, limiting the site from scaling into an active business asset.

Critical UX Flaw

Broken Navigation Funnels (404 Error Routes)

Every contextual call-to-action link inside the sidebar element ("All Services") redirects a user to an absolute file path mismatch error page (e.g., /services/service-single-1.html). This severe breakdown indicates an incomplete migration or fractured code deployment, causing high friction and immediate user bounce rates.

Critical UX Flaw

Misplaced Search Bar Isolation

The core service query input is confined to an isolated sidebar element halfway down secondary pages. For a complex, information-heavy logistics provider offering numerous regulatory clearances, global search vectors should reside natively in the header navbar to grant users instant platform navigation.

Architecture

Hardcoded Static File Dependence

The system runs entirely as a collection of static, manually managed HTML documents. This setup limits updates and introduces path discrepancies between header menus (clean routing) and footer maps (exposing legacy .html file extensions). This design hurts search visibility and blocks dynamic feature sets.

Visual Identity

High Saturated Color Fatigue

The site uses oversized, high-saturation red container backgrounds throughout its midsections. This intense color use overpowers text layers and causes rapid reader fatigue. Modern B2B branding uses neutral slates with crisp, intentional primary accents to direct attention toward essential interface interactions.

The Infrastructure Imperative

Why the Current Setup is Simple — And the Value of Evolving

The "Digital Business Card" Trap: Most logistics providers historically view a website as a digital brochure. Operations are managed over manual, fragmented channels: WhatsApp groups, long email chains, and physically printing paperwork portfolios. This fragmentation creates operational blind spots for clients. Transforming this site into a secure web application infrastructure turns it from a simple advertisement into a valuable operations portal.

Proposed Digital Infrastructure Blueprint

A modernized approach replaces static marketing with an interactive multi-portal system. The architecture addresses both client-facing trust vectors and administrative operational throughput.

M1Global Navbar Restructure

Implementation Roadmap

Weeks 1-2

Phase 1: Interface Modernization & Navigation Fixes

Deploy immediate fixes for broken links and 404 paths. Restructure the navbar header layout with the centralized service search element. Transition the visual design system to a clean, premium slate canvas featuring focused corporate accents.

Weeks 3-5

Phase 2: Database Modeling & Secure Authentication

Develop core relational data schemas for client profiles, cargo accounts, and consignment tracking paths. Set up the secure user account system and access configurations using robust modernization frameworks (such as Next.js/Laravel/Supabase).

Weeks 6-8

Phase 3: Core App Engine Development

Build out the front-end Client Operations Hub, the secure Document Vault uploading gateway, and the integrated internal agent control screens. Wire up automated message notifications to keep users informed at key clearing milestones.

Weeks 9-10

Phase 4: End-to-End System Testing & Deployment

Conduct end-to-end user tests across mobile and desktop viewports. Run security testing on file uploads and payload data handling. Train internal team on management portals before formal platform rollout.
